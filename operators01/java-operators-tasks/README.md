# Java Operators Tasks

Solutions for all 10 questions in the Operators Problem PDF.

## Run in VS Code without manually typing commands
1. Open this folder in VS Code.
2. Install Microsoft's Extension Pack for Java.
3. Open a `.java` file.
4. Click **Run** above the `main` method.
5. For input-based questions, type the requested input in the console that opens.
