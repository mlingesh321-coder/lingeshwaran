# Java Ternary Operator Practice

10 Java programs based on the uploaded problem sheet.

## Run in VS Code
1. Extract this ZIP.
2. Open the `java-ternary-practice` folder in VS Code.
3. Install Microsoft's **Extension Pack for Java** if needed.
4. Open a `.java` file and click **Run** above `main`.
5. Enter input in the console when prompted.

## Programs
1. Even or Odd
2. Greater Number
3. Positive or Negative
4. Eligible Age
5. Divisibility Check
6. Biggest of Three
7. Last Digit Is Even
8. Student Result
9. Free Delivery
10. Discount Calculator
